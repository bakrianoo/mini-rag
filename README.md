# SIKKA CHATBOT USING RAG

## Requirements

- Python 3.11 or later

#### Insall Python using Miniconda

1) Downlaod and install Miniconda from here

2) Create a new environment using the following command: 
```bash
$ conda create -n SIKKA-app python=3.11
```
3) Activate the enviornment:
```bash
$ conda activate SIKKA-app
```
### (optional) Setup your command line for better readability
```bash
export PS1=
```

## Installation

### Install the required packages
```bash
$ pip install -r requirements.txt
```
### Setup the environment variables
```bash
$ cp .env.example .env
```
Set you environment variables in the `.env` file. Like `OPENAI_API_KEY` value.
