# MINI-RAG
This is a minimal implementation og the RAG model for Q&A

## Requirements
- python 3.12 or later 

#### Insall python using MiniConda
1) Download MiniConda and Install it from (https://www.anaconda.com/docs/getting-started/miniconda/install#linux-2)

2) craete a new environment using the following command :
```bash
$ conda create -n mini-rag python =3.12
```
3) Activate the environment :
```bash 
$ conda activate mini-rag
```
4) (Optional) Setup you command line interface for better readability
```bash 
export PS1="\[\033[01;32m\]\u@\h:\w\n\[\033[00m\]\$ "
```
